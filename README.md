# Background
This repo has Dockerfiles and docker-compose files for setting up various Linux based development environments. There are different variants, layered as best as possible:

## Dockerfile variants
- **u22** - Ubuntu 22.04 LTS Base, with CLI utilities and Bash customization themes
- **u22Py** - Based on u22 image and Miniconda installed
- **u22PyDL** - Based on u22Py, with Pytorch and TensorFlow environments installed
